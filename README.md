# MacDisplayManager

用 SwiftUI 寫的 macOS 螢幕管理小工具,有兩大功能:

1. **關閉螢幕**:直接停用選定的螢幕(預設是 iMac 的內建螢幕面板;面板斷電、省電),同時保留螢幕共享的遠端操作。移動實體滑鼠時自動恢復。
2. **虛擬螢幕**:建立一個與主要顯示器綁定(鏡像)的虛擬螢幕,可自由選擇長寬比與 Retina / 標準解析度,讓螢幕共享以該解析度呈現。

> ⚠️ 這個專案使用**私有 API**(`CGSConfigureDisplayEnabled`、`CGVirtualDisplay`),僅供自用,
> 也不保證在每個 macOS 版本上都有效。使用前請務必在 Mac 前面親自測試。
> 尚未在實機驗證觸控板的偵測,但已實測可以關閉和開啟顯示器。

## 功能

### 關閉螢幕

- **選擇要關閉的螢幕**:每個螢幕一個開關(以顯示器 UUID 記憶),預設只選內建螢幕。自動關閉、啟動時關閉、外接顯示器連接時關閉,都只會套用這裡的選擇。螢幕關閉期間不能更改選擇。
- **手動切換**:視窗按鈕,或 Dock 圖示右鍵選單(「關閉選定的螢幕 / 重新開啟螢幕」)。
- **連線偵測**(給遠端使用的情境,依實體滑鼠 / 觸控板是否連線,藍牙或有線皆可):
  - 「連線時自動開啟螢幕」:裝置連上時恢復螢幕。關閉此選項會先跳出確認對話框。
  - 「斷線時自動關閉螢幕」:裝置全部斷線時關閉螢幕。
- **滑鼠移動或連線時也不開啟螢幕**(預設關):啟用後本機無法再靠滑鼠 / 觸控板喚醒,啟用前必須通過三步確認。只能從遠端按「重新開啟螢幕」、結束 App 或重新開機恢復。
  例外:關螢幕時若還有其他螢幕,之後其餘螢幕全被移除,會自動恢復被關閉的螢幕,避免變成沒有任何螢幕。
- **外接顯示器**:「外接顯示器連接時,關閉選定的螢幕」。接上外接顯示器時自動關閉,移除後自動恢復(只恢復被這個選項關掉的)。虛擬螢幕不算外接顯示器。
- **啟動**:
  - 「登入時開啟 App(隱藏視窗)」:Dock 圖示仍在,點擊可再顯示視窗。
  - 「開啟 App 時」:恢復上次狀態、開啟螢幕或關閉螢幕。
- 預設無論自動或手動關閉,都必須能用實體滑鼠 / 觸控板恢復,所以關閉前會先確認實體裝置監聽可以啟動,失敗就不會關閉。
- 即使系統沒偵測到連線,只要有實體滑鼠 / 觸控板的操作也會開啟(之後要等下一次裝置連上或移除才會再自動關閉)。

### 虛擬螢幕

- 左邊選**長寬比**:16:9、16:10、4:3、21:9、32:9、10.5:9。
- 右邊選**解析度**,分兩區:
  - Retina(2K 到 8K,各 5 種)
  - 標準解析度(各 10 種)
- 選定後即建立(或更換)虛擬螢幕,目前使用的解析度會打勾。
- 虛擬螢幕為主,建立前的主要顯示器會鏡像它,所以解析度與螢幕共享都以虛擬螢幕為準。
- 虛擬螢幕只會建立一次,之後切換解析度只更新模式,鏡像不會中斷。
- 「移除虛擬螢幕」會解除鏡像並**重新啟動 App**(虛擬螢幕隸屬本行程,行程結束系統才會移除)。
- 虛擬螢幕不會出現在「要關閉的螢幕」列表。

## 運作方式

| 元件 | 說明 |
| --- | --- |
| `PanelController` | 呼叫 `CGSConfigureDisplayEnabled` 停用選定的螢幕,並以 `IOPMAssertion` 阻止閒置熄屏 |
| `MouseWatcher` | 用 `IOHIDManager` 監聽**實體** HID 滑鼠與觸控板(含 Magic Mouse / Magic Trackpad),有動作就恢復螢幕(遠端注入的事件不經過 HID 裝置,不會誤觸發) |
| `PointerPresence` | 即時追蹤實體滑鼠 / 觸控板是否連線,供連線偵測選項使用 |
| `DisplayWatcher` | 監看顯示器組態變動,供外接顯示器規則與安全閥使用 |
| `VirtualDisplayController` | 以 `CGVirtualDisplay` 建立單一虛擬顯示器,並用 `CGConfigureDisplayMirrorOfDisplay` 讓主要顯示器鏡像它 |
| 看門狗 `mdm-watchdog` | `.app` 內的獨立行程,盯著主程式 PID;主程式以任何方式結束(包含 Force Quit / `kill -9`)都會把螢幕重新啟用 |
| 啟動自救 | 停用的顯示器 ID 會存進 `UserDefaults`,下次啟動時先重新啟用 |

為什麼不用 `pmset displaysleepnow`?顯示器睡眠後 WindowServer 不再繪製畫面,螢幕共享會變黑、無法操作。

## 需求

- macOS 13 以上(arm64 / x86_64 universal)
- Xcode Command Line Tools(需要 `swiftc`、`iconutil`、`codesign`)

## 建置與執行

```sh
./build.sh
open MacDisplayManager.app
```

`build.sh` 會編譯 arm64 與 x86_64、合併為 universal、複製看門狗執行檔、放入圖示,並以 ad-hoc 簽署。

## 使用

1. 開啟 App,在「關閉螢幕」頁勾選要關的螢幕,按「關閉選定的螢幕」(或在 Dock 圖示上按右鍵選同樣的項目)。
2. 面板關閉後,仍可由螢幕共享連線操作。運作期間不會自動熄屏。
3. 移動實體滑鼠即可恢復;也可從遠端按「重新開啟螢幕」,或結束 App。
4. 需要特定解析度的遠端畫面時,切到「虛擬螢幕」頁選長寬比與解析度。
5. 關閉視窗不會退出 App,Dock 圖示會常駐;從 Dock 結束 App 會恢復螢幕。

## 緊急恢復

- 動一下實體滑鼠。
- 從遠端或 SSH:`pkill MacDisplayManager`(會先恢復螢幕再結束),或直接 Force Quit,看門狗會在約 1 秒內恢復。
- 重新開啟 App(啟動時會恢復上次被停用的螢幕)。
- 最後手段:重新開機。

## 已知限制

- macOS 可能拒絕停用最後一個顯示器;失敗時 App 會顯示錯誤訊息,螢幕維持不變。
- 螢幕全部停用後選單列與 Dock 都看不到,因此恢復只能靠實體滑鼠、遠端操作或結束 App。
- 觸控板的偵測依賴其 HID 回報格式,尚未在實機驗證;若觸控板沒有反應,請先改用滑鼠。
- 「登入時開啟 App(隱藏視窗)」依賴系統的啟動事件,尚未在實機驗證。
- 螢幕共享期間系統若建立虛擬顯示器,可能被「滑鼠移動或連線時也不開啟螢幕」的安全閥當成其他螢幕。
